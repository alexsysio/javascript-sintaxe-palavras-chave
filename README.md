### Palavras-chave JavaScript

Instruções JavaScript frequentemente começam com uma palavra-chave para identificar a ação a ser executada.

| Palavra-chave | Descrição |
| :--- | :--- |
| `var` | Declara uma variável |
| `let` | Declara uma variável de bloco |
| `const` | Declara uma constante de bloco |
| `if` | Marca um bloco de instruções a serem executadas sob uma condição |
| `switch` | Marca um bloco de instruções a serem executadas em diferentes casos |
| `for` | Marca um bloco de instruções a serem executadas em um loop |
| `function` | Declara uma função |
| `return` | Sai de uma função |
| `try` | Implementa o tratamento de erros em um bloco de instruções |

> Palavras-chave em JavaScript são palavras reservadas. Palavras reservadas não podem ser usadas como nomes para variáveis.

&nbsp;
