### Palavras-chave JavaScript
### Palavras-chave em JavaScript são usadas para definir ações a serem realizadas.
### As palavras-chave criam variáveis: let const

&nbsp;

### Palavras-chave JavaScript são sensíveis a maiúsculas e minúsculas.
### O JavaScript não interpreta LET ou Let como a palavra-chave let.

&nbsp;

### Palavras-chave JavaScript
### Instruções JavaScript frequentemente começam com uma palavra-chave para identificar a ação JavaScript a ser executada.
### Palavra-chave &nbsp; Descrição
### var &nbsp; Declara uma variável
### let &nbsp; Declara uma variável de bloco
### const &nbsp; Declara uma constante de bloco
### if &nbsp; Marca um bloco de instruções a serem executadas sob uma condição
### switch &nbsp; Marca um bloco de instruções a serem executadas em diferentes casos
### for &nbsp; Marca um bloco de instruções a serem executadas em um loop
### function &nbsp; Declara uma função
### return &nbsp; Sai de uma função
### try &nbsp; Implementa o tratamento de erros em um bloco de instruções

&nbsp;

### Palavras-chave em JavaScript são palavras reservadas. Palavras reservadas não podem ser usadas como nomes para variáveis.

&nbsp;
